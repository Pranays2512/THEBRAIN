## 🚀 Building and Running

### Prerequisites
- C++17 compatible compiler (`clang++` / `g++`)
- CMake 3.16+
- Java JDK 11+ (with `javac` and `java` available on PATH)

### 1. Build the Native C++ / JNI Core
```bash
cd brain3
mkdir -p build_cmake && cd build_cmake
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . --target brainjni -j4
cd ../..
```

### 2. Compile the Java Faculty Layer & Test Suites
```bash
javac -cp "brain3/json-20231013.jar:brain3/vendor/json.jar" \
      -d brain3/out_java \
      brain3/adapters/java/src/brain3/*.java \
      brain3/faculties/java/src/brain3/faculties/*.java
```

### 3. Run the Grand Regression Suite
```bash
java -Djava.library.path=brain3/build_cmake -cp "brain3/out_java:brain3/json-20231013.jar" brain3.InstinctEngineTest
java -Djava.library.path=brain3/build_cmake -cp "brain3/out_java:brain3/json-20231013.jar" brain3.STEMDomainExpansionTest
java -Djava.library.path=brain3/build_cmake -cp "brain3/out_java:brain3/json-20231013.jar" brain3.AutonomousCuriosityTest
java -Djava.library.path=brain3/build_cmake -cp "brain3/out_java:brain3/json-20231013.jar" brain3.ScientificDiscoveryTest
java -Djava.library.path=brain3/build_cmake -cp "brain3/out_java:brain3/json-20231013.jar" brain3.MetacognitiveSelfRefutationTest
java -Djava.library.path=brain3/build_cmake -cp "brain3/out_java:brain3/json-20231013.jar" brain3.StructuralAnalogyTest
```
