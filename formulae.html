Hopf Network Dynamics
dΨ/dt = j·ω·Ψ + W·Ψ + α·Δ·Ψ
      + g(ξ,R)·Ψ − γ·|Ψ|²·Ψ − A·Ψ
      + σ·noise + W_in·I·g_in
RK4 integration, dt=0.05s. Ψ∈ℂ⁵⁰⁰. ω=logspace(0.4,2.2,500)×2π
Nonlinear Gain g(ξ,R)
R = Re(Ψ* · W·Ψ) / (|Ψ|² + |W·Ψ|²)
g = ξ · tanh(1 − R) − λ
λ=0.8 ξ∈[0.1,3.0] adaptive gain
Adaptation A (per neuron)
dA/dt = (κ·max(E − E_target, 0) − A) / τ_A
E_avg ← 0.99·E_avg + 0.01·|Ψ|²
κ=0.5 E_target=2.5 A∈[0,2]
Leaky Phasor (PLV computation)
φ_in = 2π·f·t
phasor = exp(j·(∠Ψ − φ_in))
X_plv ← (1−α)·X_plv + α·phasor
α_fast = dt/τ_fast (τ=1s) α_slow = dt/τ_slow (τ=5s)
PLV Decoder (raw frequency)
w_i = |PLV_i|⁸ · E_i
f_raw = Σ(ω_i · w_i) / Σ(w_i)
PLV sharpening exponent=8. Weighted centroid over oscillator bank.
Calibrated Decode + Fusion
f_cal = interp(f_raw; table)
w = stability(PLV_history)
f_fused = w·f_slow + (1−w)·f_fast
Reverse lookup table (44 cal pts). w∈[0,1] from PLV min over 20-step window.
PLV Stability Weight
plv_min = min(PLV_history_20)
w = clip((plv_min − 0.30) / (0.90 − 0.30), 0, 1)
0 = unstable/sweeping. 1 = fully locked to frequency.
CUSUM Change Detector
div = |f_fast − f_slow|
if w < 0.30: accum = 0 (gated)
else: accum += max(div − 0.038, 0)
novel = (accum > 0.038)
Threshold=0.038 Hz. Gate prevents false positives during settling.
Hebb + Lyapunov (training)
ΔW[i,j] = η·Re(Ψ_i·Ψ_j*)·|Ψ_i||Ψ_j|
W ← W·(1 − δ·W)
α ← α + η_α·(λ_target − λ̄)
η=0.002 δ=0.0001. Lyapunov target=0.1. Used only during first 60s.

Input Preparation
freq_norm = clip((f − 0.41)/(2.20−0.41), 0, 1)

BMU Selection (Conscience)
d[i] = ||x − W[i]||²
d_eff[i] = d[i] · (1 + 0.5·(p[i] − 1/64))
BMU = argmin(d_eff)
Conscience prevents any neuron from winning too often. QE = √d[BMU]
Learning Rate η
η_base = 0.01 + 0.14·w
η_curiosity = 0.14·2.0·qe_norm
η_sequence = 0.14·1.0·PE
η_fam = 1.5·0.14·familiarity
η = clip(η_base + η_cur + η_seq − η_fam, 0.01, 0.30)
Familiarity suppresses (LTD). Prediction error boosts. Novel input overrides.
Neighbourhood Function h
σ = 0.8 + (3.5−0.8)·mean(surprise_hist)
h[i] = exp(−grid_dist²[BMU,i] / 2σ²)
σ_min=0.8 (consolidation). σ_max=3.5 (exploration). 100-step history.
Weight Update
ΔW[i] = η · h[i] · (x − W[i])
W ← clip(W + ΔW, 0, 1)
Surprise (EMA-based qe_norm)
qe_norm = clip((QE − QE_ema)/(QE_ema + ε), 0, 1)
QE_ema ← 0.99·QE_ema + 0.01·QE
p[i] ← p[i] + 0.002·(win[i] − p[i])
Surprise = excess above familiar baseline. Conscience win-freq EMA.

Adaptive Eligibility Trace
τ_decay = max(0.02, 0.05 − 0.03·qe_norm)
trace ← trace · (1 − τ_decay)
trace[BMU] = 1.0
Novel input → slow decay → longer memory window (~40 steps). Familiar → ~10 steps.
Hebbian Weight Update
η_eff = 0.04·(1 + curiosity + RPE·pos_rpe)
ΔW = η_eff · outer(trace, trace)
diag(ΔW) = 0
W ← W + ΔW
Only neurons with trace ≥ 0.05 participate. Curiosity doubles η at max.
Decay + Homeostasis
W ← W · (1 − 0.0005)
W ← W · clip(1/(max_row+ε), ·, 1) [row norm]
W ← (W + Wᵀ) · 0.5 [symmetry]
τ_forget≈2000 steps. Row max capped at W_MAX=1. Symmetric association.
Recall — Pattern Completion
activation = W · pattern
new_pattern = softmax(activation / 0.5)
new_pattern[BMU] = max(new_pattern[BMU], 0.5) [anchor]
repeat ≤10 steps until peak_non_cue > 0.15
Hopfield-style settling. E = −½ pᵀWp. Convergence when recalled pattern reaches confidence threshold.

L2 PREDICTOR
Sequence memory
P matrix 64×64
Context vector c
Prediction (before BMU fires)
raw_scores = Pᵀ · c (64,)
exp_s = exp((raw − max) / T) T=0.15
norm_scores = exp_s / Σexp_s
predicted_BMU = argmax(norm_scores)
Softmax with T=0.15 sharpens competition. Confidence = (top − 1/64)/(1 − 1/64).
Spatial Prediction Error
dist² = (row_pred−row_act)² + (col_pred−col_act)²
PE = 1 − exp(−dist² / 2·σ²) σ=2.0
PE ← PE · (1 − 0.3·familiarity)
Grid distance on 8×8 cortex. Familiarity reduces PE by up to 30%.
Adaptive Context Decay
τ_c = max(0.10, 0.30 − 0.20·PE)
c ← c · (1 − τ_c)
c[BMU] = 1.0 (after learning)
High PE → slow decay → longer context window (~10 steps). Low PE → ~3 steps.
P Matrix Update (STDP-inspired)
η = 0.05 + 0.10·PE (if PE>0.5)
active = (c ≥ 0.50)
P[:,BMU] += η · c · active
P[BMU,BMU] = 0 (no self-predict)
P[:,BMU] ← clip(P[:,BMU], 0, P_MAX)
Context that preceded BMU gets credit. Learning BEFORE imprint. Causal order.
P Decay + Normalisation
P ← P · (1 − 0.001) τ≈1000 steps
col_max = P.max(axis=0)
P ← P · (P_MAX / max(col_max, P_MAX))
Column-wise normalisation prevents monopoly. τ=1000 keeps rare transitions.

Zone Probability Prediction

Calibration Score (primary metric)
g[j] = grammar_prob[src→j] (sparse, sums to 1)
calib = dot(zone_probs, g) / dot(g, g)

calib = 1.0 ↔ Z perfectly mirrors grammar
calib > 1.0 ↔ Z over-concentrates on top successor
calib = 0.0 ↔ Z predicts invalid successors only
Normalised inner product. Rewards distributional accuracy, not just top-1. Tie zones (50/50) correctly score 1.0.

Delta Rule (EMA)

Gate Entropy
H = −Σ gate[i] · log(gate[i])
gate_entropy = H / log(64)
0 = maximally focused (single neuron). 1 = uniform (diffuse attention).

Intrinsic + Total Reward
intrinsic = 1 − PE
total_reward = 0.5·reward + 0.5·intrinsic
  (pure intrinsic if reward=0)
Perfect prediction = max intrinsic reward. External reward blended equally.
Reward Prediction Error (RPE)
RPE = clip(total_reward − EMA, −1, 1)
pos_RPE = max(RPE, 0)
neg_RPE = max(−RPE, 0)
EMA ← (1−0.05)·EMA + 0.05·total_reward
Signed deviation above/below expected reward. Dopamine analogue.
Prediction Bias (L2 + M55 blend)
l2_bias = normalise(P_top_k(attended_BMU))
m55_bias = normalise(W[attended_BMU])
bias = 0.6·l2_bias + 0.4·m55_bias
bias /= Σbias
L2 = temporal sequence. M55 = associative co-occurrence. Falls back to uniform if no signal.
Thought Confidence + Delta
raw_conf = clip(max(bias) − 1/64, 0, 1)
conf_delta = clip(raw_conf − EMA, 0, 1)
EMA ← (1−0.1)·EMA + 0.1·raw_conf
Spike when Thought suddenly forms a clear prediction. Suppresses Attention slightly.
